# PerPlayerProfiles roadmap

The following ideas were selected from the original list of 100 suggestions. Six are included in 1.0.0; the other 22 remain planned without a target version.

## Implemented in 1.0.0

| Idea | Feature |
| --- | --- |
| 9 | Independently tracked discovered recipes. |
| 10 | Independent statistics for blocks, items and entities. |
| 18 | Profile creation date in details and hover information. |
| 19 | Last connection date in details and hover information. |
| 29 | Optional transition animation when switching characters. |
| 99 | Language selection for each player, including client language detection. |
